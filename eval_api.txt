
===========================================
评测相关 API
===========================================
------------------------------------------
11.获取评测任务列表
------------------------------------------
GET /api/evaluation

成功响应(200):
{
  "code":200
  "msg":"success"
  "data":{
    [
      "id":1
      "name":任务名称
      "creator":任务创建者
      "evalMethod"：评测方法
      "state"：状态
      "createdAt"：创建时间
    ],
    [
      ...
    ]
  }
}

失败响应（400）：
{
  "code":400
  "msg":"拉取评测任务失败"
}

------------------------------------------
12.查看客观评测报告
------------------------------------------
GET /api/evaluation/{id}

成功响应（200）
{
  "code":200
  "msg":"success"
  "name":任务名称
  "dataset":使用数据集
  "model":使用模型
  "evalMethod":评测方法
  "createdAt":创建时间
  "timeUsed":评测用时
  "testCount":测试数量
  "correctCount":正确数量
  "accurary":正确率
  "score":得分
  "result_detail":{
    [
      "id":条目id
      "content":条目内容
      "correctAnswer":正确答案
      "predictedAnswer":预测答案
      "isCorrect":是否正确
    ]，
    [
      ...
    ]
  }
}

------------------------------------------
13.创建评测任务
------------------------------------------
POST /api/evaluation

请求体：
{
  "name":任务名称
  "model-id":模型id
  "dataset-id":数据集id
  "evalMethod":评测方法
  “createdAt":创建时间
}
