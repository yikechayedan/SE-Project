# ⚡ 快速部署速查表

## 🎯 核心命令（复制粘贴版）

### 1️⃣ 登录服务器
```bash
ssh root@你的服务器IP
```

### 2️⃣ 安装 Docker（一行命令）
```bash
curl -fsSL https://get.docker.com | sh && systemctl start docker && systemctl enable docker && curl -L "https://github.com/docker/compose/releases/download/v2.24.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose && chmod +x /usr/local/bin/docker-compose
```

### 3️⃣ 克隆项目
```bash
cd /opt && git clone https://github.com/你的用户名/SE-Project.git && cd SE-Project
```

### 4️⃣ 配置环境
```bash
cd deploy && cp .env.example .env
# 生成密钥
python3 -c "import secrets; print(secrets.token_urlsafe(50))"
# 编辑 .env 文件
nano .env
```

### 5️⃣ 一键部署
```bash
bash scripts/deploy.sh
```

---

## 📝 必须修改的 3 个密码

打开 `.env` 文件，修改这 3 行：

```bash
SECRET_KEY=粘贴刚才生成的随机密钥
DB_PASSWORD=你的数据库密码（自己设置）
REDIS_PASSWORD=你的Redis密码（自己设置）
```

如果有域名或知道服务器 IP，也修改这两行：
```bash
ALLOWED_HOSTS=123.45.67.89,你的域名.com
CORS_ALLOWED_ORIGINS=http://123.45.67.89,https://你的域名.com
```

## 🔍 验证部署

```bash
# 查看容器状态
cd /opt/SE-Project/deploy/docker
docker-compose ps

# 查看日志
docker-compose logs -f
```

- **前端**: http://服务器IP
- **后端API**: http://服务器IP:8080/api/
- **管理后台**: http://服务器IP:8080/admin/

## 🛠️ 日常运维

```bash
# 停止
cd /opt/SE-Project/deploy && bash scripts/stop.sh

# 启动
cd /opt/SE-Project/deploy && bash scripts/start.sh

# 更新
cd /opt/SE-Project/deploy && bash scripts/update.sh

# 查看日志
cd /opt/SE-Project/deploy/docker && docker-compose logs -f backend
```

## ⚠️ 防火墙（如果无法访问）

```bash
# Ubuntu/Debian
ufw allow 80 && ufw allow 8080

# CentOS
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=8080/tcp
firewall-cmd --reload
```

## 🆘 常见错误

### 端口被占用
```bash
netstat -tlnp | grep :80
kill -9 <PID>
```

### 容器启动失败
```bash
docker-compose logs backend
docker-compose restart backend
```

### 忘记改配置
```bash
cd /opt/SE-Project/deploy
nano .env
cd docker && docker-compose down && docker-compose up -d
```
