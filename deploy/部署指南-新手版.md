# 🚀 PolyMetric 服务器部署指南（新手版）

## 📋 准备工作

### 你需要准备的信息：
- ✅ 服务器 IP 地址（例如：123.45.67.89）
- ✅ 服务器用户名（通常是 root 或其他管理员账号）
- ✅ 服务器密码或 SSH 密钥
- ✅ Git 仓库地址（你的项目 GitHub/GitLab 地址）

---

## 第一步：登录服务器

### Windows 用户：
```bash
# 方法1: 使用 PowerShell 或 CMD
ssh root@你的服务器IP
# 例如: ssh root@123.45.67.89

# 方法2: 使用 Xshell/PuTTY 等工具
# 打开工具 → 新建连接 → 输入 IP 和密码
```

### Mac/Linux 用户：
```bash
# 打开终端
ssh root@你的服务器IP
```

输入密码后，看到类似 `root@server:~#` 就表示登录成功了。

---

## 第二步：安装必要软件

登录服务器后，依次执行下面的命令：

```bash
# 1. 更新系统包
apt update && apt upgrade -y

# 2. 安装 Docker（容器运行环境）
curl -fsSL https://get.docker.com | sh

# 3. 启动 Docker 服务
systemctl start docker
systemctl enable docker

# 4. 安装 Docker Compose（容器编排工具）
curl -L "https://github.com/docker/compose/releases/download/v2.24.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 5. 验证安装
docker --version
docker-compose --version
# 看到版本号就说明安装成功

# 6. 安装 Git（如果没有）
apt install git -y
```

---

## 第三步：拉取项目代码

```bash
# 1. 进入工作目录
cd /opt  # 或者你喜欢的其他目录

# 2. 克隆项目（替换成你的仓库地址）
git clone https://github.com/你的用户名/SE-Project.git
# 如果是私有仓库，需要输入 GitHub 用户名和密码（或 Token）

# 3. 进入项目目录
cd SE-Project
ls  # 查看文件，应该能看到 PolyMetric、deploy 等文件夹
```

---

## 第四步：配置环境变量（⚠️ 重要）

```bash
# 1. 进入 deploy 目录
cd deploy

# 2. 复制配置模板
cp .env.example .env

# 3. 编辑配置文件
nano .env
# 如果没有 nano，用 vi: vi .env
```

### 必须修改的配置项：

打开 `.env` 文件后，修改下面这些值：

```bash
# ⚠️ Django 密钥（必改！生成一个随机字符串）
SECRET_KEY=your-random-secret-key-at-least-50-characters-long

# ⚠️ 数据库密码（必改！设置一个强密码）
DB_PASSWORD=你的数据库密码123

# ⚠️ Redis 密码（必改！设置一个强密码）
REDIS_PASSWORD=你的Redis密码456

# ⚠️ 服务器域名或IP（如果有域名就填域名，没有就填 IP）
ALLOWED_HOSTS=123.45.67.89,www.你的域名.com,你的域名.com
CORS_ALLOWED_ORIGINS=http://123.45.67.89,https://www.你的域名.com

# 其他可选配置（暂时可以不改）
DB_NAME=polymetric
DB_USER=polymetric_user
HTTP_PORT=8080
HTTPS_PORT=8443
```

**如何生成 SECRET_KEY?**
```bash
# 在服务器上执行这个命令生成随机密钥
python3 -c "import secrets; print(secrets.token_urlsafe(50))"
# 把输出结果复制到 SECRET_KEY= 后面
```

**保存并退出编辑器：**
- nano: 按 `Ctrl + X`，然后按 `Y`，再按 `Enter`
- vi: 按 `Esc`，输入 `:wq`，按 `Enter`

## 第五步：一键部署 🎉

```bash
# 确保你在 deploy 目录下
pwd  # 应该显示 /opt/SE-Project/deploy

# 运行部署脚本
bash scripts/deploy.sh
```

**部署过程需要 5-15 分钟，你会看到：**
```
🚀 开始部署 PolyMetric...
📥 拉取最新代码...
🏗️  构建 Docker 镜像...（这一步最慢，耐心等待）
🚢 启动容器...
⏳ 等待服务启动...
✅ 部署完成！
```

## 第六步：验证部署

```bash
# 1. 查看所有容器是否正常运行
cd docker
docker-compose ps

# 你应该看到 6 个容器都是 "Up" 状态：
# polymetric-db           Up (healthy)
# polymetric-redis        Up (healthy)
# polymetric-backend      Up
# polymetric-celery-worker Up
# polymetric-frontend     Up
# polymetric-nginx        Up

# 2. 查看日志（如果有错误）
docker-compose logs backend
docker-compose logs frontend
```

---

## 第七步：访问网站

在浏览器打开：
- **前端页面**: `http://你的服务器IP`
- **后端 API**: `http://你的服务器IP:8080/api/`
- **管理后台**: `http://你的服务器IP:8080/admin/`

**注意**：如果无法访问，需要在服务器防火墙开放端口：
```bash
# Ubuntu/Debian
ufw allow 80
ufw allow 8080
ufw allow 8443

# CentOS/RHEL
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=8080/tcp
firewall-cmd --reload
```

## 🛠️ 常用操作

### 停止服务
```bash
cd /opt/SE-Project/deploy
bash scripts/stop.sh
```

### 启动服务
```bash
cd /opt/SE-Project/deploy
bash scripts/start.sh
```

### 更新代码
```bash
cd /opt/SE-Project/deploy
bash scripts/update.sh
```

### 查看日志
```bash
cd /opt/SE-Project/deploy/docker
docker-compose logs -f backend      # 查看后端日志
docker-compose logs -f frontend     # 查看前端日志
docker-compose logs -f              # 查看所有日志
# 按 Ctrl+C 退出日志查看
```

### 重启单个服务
```bash
cd /opt/SE-Project/deploy/docker
docker-compose restart backend      # 重启后端
docker-compose restart nginx        # 重启 Nginx
```

## ❓ 常见问题

### Q1: 端口被占用怎么办？
```bash
# 查看占用 80 端口的进程
netstat -tlnp | grep :80
# 或者
lsof -i :80

# 杀掉占用进程（替换 PID 为实际进程号）
kill -9 <PID>
```

### Q2: 如何修改后端代码后重新部署？
```bash
cd /opt/SE-Project
git pull                    # 拉取最新代码
cd deploy
bash scripts/update.sh      # 重新构建并部署
```

### Q3: 数据库数据会丢失吗？
不会！Docker 使用 Volume 持久化存储，即使重启容器数据也会保留。

### Q4: 如何备份数据库？
```bash
cd /opt/SE-Project/deploy/docker
docker-compose exec db pg_dump -U polymetric_user polymetric > backup_$(date +%Y%m%d).sql
```

### Q5: 忘记修改 .env 怎么办？
```bash
cd /opt/SE-Project/deploy
nano .env              # 修改配置
cd docker
docker-compose down    # 停止服务
docker-compose up -d   # 重新启动
```

## 🔒 安全提示

1. **必须修改密码**: DB_PASSWORD、REDIS_PASSWORD、SECRET_KEY
2. **防火墙配置**: 只开放必要端口（80、443、8080）
3. **定期备份**: 每周备份数据库
4. **更新系统**: 定期执行 `apt update && apt upgrade`
5. **监控日志**: 定期检查 `docker-compose logs` 是否有异常
