# PolyMetric 高并发测试系统设计与实现总结

## 项目概述

本项目为PolyMetric系统设计并实现了一套完整的高并发测试方案，专门用于测试系统在5000并发请求下的负载承载能力，特别关注Celery和Redis在高并发下的表现。

## 系统架构

### 测试组件

1. **综合高并发负载测试** (`test_high_concurrency_load.py`)
   - 模拟多用户同时上传大文件和提交评测任务
   - 监控系统资源使用情况（CPU、内存、磁盘IO、网络IO）
   - 测试数据集上传、评测任务创建、运行和状态查询

2. **评测任务并发测试** (`test_evaluation_tasks_concurrent.py`)
   - 专门测试Celery和Redis在高并发下的表现
   - 监控任务队列长度、活跃任务数量、任务完成时间
   - 测试客观评测、主观评测和对抗评测任务

3. **混合API负载测试** (`test_mixed_load_simple.py`)
   - 模拟5000个并发用户同时访问不同的API端点
   - 测试排行榜、数据集、模型、系统、用户关注等API

4. **大模型API并发测试** (`test_llm_api_5000_concurrent.py`)
   - 专门测试大模型API在5000个并发请求下的性能表现
   - 测试大模型评估、对话和状态查询API

5. **真实大模型API并发测试** (`test_real_llm_api_5000_concurrent.py`)
   - 基于项目中实际存在的大模型相关API端点进行测试
   - 测试评测任务创建、运行、状态查询和基准测试

### 监控组件

1. **系统资源监控器** (`SystemResourceMonitor`)
   - 监控CPU使用率、内存使用率、磁盘IO、网络IO
   - 监控Redis内存使用和队列长度
   - 每秒采集一次指标，提供实时监控数据

2. **Celery和Redis监控器** (`CeleryRedisMonitor`)
   - 专门监控Celery和Redis的性能指标
   - 监控任务队列长度、活跃任务数量、任务完成时间
   - 记录任务成功率和失败率

### 执行组件

1. **测试运行器** (`HighConcurrencyTestRunner`)
   - 自动运行所有测试脚本
   - 收集测试结果并生成综合报告
   - 提供统一的测试执行入口

2. **结果分析器** (`TestResultAnalyzer`)
   - 分析测试结果并生成可视化报告
   - 生成性能分析图表、资源使用分析图表
   - 生成Markdown格式的测试分析摘要报告

## 技术实现

### 并发测试技术

1. **线程池并发**
   - 使用`ThreadPoolExecutor`实现真正的并发请求
   - 支持自定义最大工作线程数
   - 使用`as_completed`收集任务结果

2. **权重分布算法**
   - 实现基于权重的随机操作选择
   - 支持不同操作类型的权重配置
   - 确保测试场景的真实性

3. **动态数据生成**
   - 自动创建测试用户、模型和数据集
   - 动态生成测试数据集文件
   - 支持自定义文件大小和格式

### 监控技术

1. **系统资源监控**
   - 使用`psutil`库获取系统资源信息
   - 实时监控CPU、内存、磁盘IO、网络IO
   - 支持跨平台监控

2. **Redis监控**
   - 使用`redis-py`库连接Redis
   - 监控内存使用、连接数、命令处理数
   - 监控Celery队列长度和任务状态

3. **数据采集与存储**
   - 时间序列数据采集
   - 结构化数据存储
   - 支持后续分析和可视化

### 报告生成技术

1. **统计分析**
   - 计算平均值、最大值、最小值、百分位数
   - 计算成功率和错误率
   - 计算请求每秒（RPS）

2. **可视化图表**
   - 使用`matplotlib`生成性能分析图表
   - 使用`pandas`进行数据处理
   - 支持中文显示

3. **多格式报告**
   - JSON格式的详细数据报告
   - PNG格式的可视化图表
   - Markdown格式的摘要报告

## 使用指南

### 环境准备

1. **系统要求**
   - Python 3.8+
   - Django 5.2.8+
   - PostgreSQL 数据库
   - Redis 服务器
   - 足够的系统资源

2. **依赖安装**
   ```bash
   pip install -r requirements.txt
   pip install matplotlib pandas psutil redis
   ```

3. **服务配置**
   - PostgreSQL数据库配置
   - Redis服务器配置
   - Celery Worker配置

### 测试执行

1. **快速开始**
   ```bash
   # Windows
   run_high_concurrency_tests.bat
   
   # Linux/Unix
   ./run_high_concurrency_tests.sh
   
   # Python
   python run_high_concurrency_tests.py
   ```

2. **单独测试**
   ```bash
   python test_high_concurrency_load.py
   python test_evaluation_tasks_concurrent.py
   ```

3. **结果分析**
   ```bash
   python analyze_test_results.py
   ```

### 自定义配置

1. **并发数量**
   ```python
   tester.run_concurrent_requests(5000)  # 修改并发数
   ```

2. **操作权重**
   ```python
   self.test_config = {
       'dataset_upload': {'weight': 30, 'file_size_mb': 10},
       'evaluation_task_create': {'weight': 25},
       # ...
   }
   ```

3. **监控间隔**
   ```python
   time.sleep(1)  # 调整监控间隔
   ```

3. **可扩展性**
   - 模块化设计
   - 易于添加新的测试场景
   - 支持不同的监控指标

4. **可视化**
