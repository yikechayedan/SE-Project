# CSV数据集审核检测流程说明（更新版）

## 概述

用户上传CSV数据集后，系统会经过一系列自动化审核和检测流程，以确保数据集的质量和适用性。整个流程包括格式验证和能力分析两个主要阶段，不再需要人工审核。

## 详细流程

### 1. 数据上传阶段

#### 1.1 文件上传
- 用户通过 `POST /api/datasets/` 接口上传CSV数据集
- 系统检查文件基本属性：
  - 文件大小不超过100MB
  - 文件格式为支持的类型（CSV、JSON、ZIP）

#### 1.2 初始验证
- **文件格式验证**：检查CSV文件是否可以正确解析
- **编码检测**：系统会尝试使用多种编码解析文件（UTF-8、GBK、GB2312、Latin-1）
- **基本结构验证**：确保文件不为空，第一行包含表头

#### 1.3 测评类型特定验证
系统根据用户选择的测评类型（subjective/objective/adversarial）进行特定验证：

**主观测评 (subjective)**：
- CSV必须包含 `input` 和 `reference` 列
- `input` 和 `reference` 列的值必须是非空字符串
- 系统会检查每一行数据是否包含这两列的值

**客观测评 (objective)**：
- CSV必须包含 `input` 和 `answer` 列
- `input` 列必须包含至少两个选项（如 A. B. C.）
- `answer` 列必须是单个选项字母（如 A/B/C）
- 系统会验证答案是否在题目选项中

**对抗测评 (adversarial)**：
- CSV必须包含 `input` 列
- `input` 列的值必须是非空字符串
- 系统会检查每一行数据是否包含input列的非空值

### 2. 数据集创建与状态初始化

#### 2.1 数据集记录创建
- 验证通过后，系统创建数据集记录
- 设置初始状态：
  ```python
  is_verified = False  # 未通过验证
  capability_tag = "processing"  # 正在处理
  capability_dimension = "other"  # 默认能力维度
  ```

#### 2.2 文件信息统计
- 计算文件大小（MB）
- 统计样本数量（CSV行数减去表头）
- CSV文件不包含图片，所以 `has_images=False`, `image_count=0`

### 3. CSV数据处理与转换

#### 3.1 CSV数据抽样
- 系统从CSV文件中抽取前5行数据（不包括表头）
- 将CSV行数据转换为JSON格式，便于统一处理：
  ```python
  # 转换示例
  {
    "input": row["input"],  # 输入内容
    "reference": row["reference"],  # 主观测评的参考答案
    "answer": row["answer"]  # 客观测评的正确答案
  }
  ```

#### 3.2 字段映射与转换
- 系统会自动识别常见的字段名：
  - 输入字段：`input`, `question`, `prompt`, `text`
  - 答案字段：`answer`, `label`, `target`, `correct_answer`
  - 参考答案字段：`reference`, `answer`, `target`, `correct_answer`
- 如果没有找到标准字段名，会使用第一个非空字段作为输入

### 4. 异步能力分析

#### 4.1 触发异步任务
- 数据集创建成功后，系统自动触发 `analyze_dataset_capability` 异步任务
- 该任务使用Celery在后台执行，不阻塞用户操作

#### 4.2 能力维度分析过程
1. **CSV抽样**：从CSV文件中抽取前5条样本并转换为JSON格式
2. **AI判断**：调用大模型分析样本，判断数据集的能力维度：
   - `language`：自然语言理解、生成、翻译等
   - `reasoning`：数学推理、逻辑推理等
   - `coding`：代码生成、代码理解等

#### 4.3 验证结果处理
- **格式验证通过 + 能力分析成功**：设置 `is_verified=true`
- **任一环节失败**：设置 `is_verified=false`，记录错误原因

#### 4.4 能力分析状态更新
分析结果可能的状态：
- `processing`：正在分析中
- `no_file`：文件缺失，无法进行能力分析
- `no_samples`：无有效样本，无法进行能力分析
- `analysis_failed`：分析失败，请检查数据集格式或稍后重试
- `language/reasoning/coding`：分析成功

### 5. 验证结果处理

#### 5.1 验证成功
- 格式验证和能力分析都通过的数据集：
  - `is_verified` 自动设置为 `true`
  - `capability_tag` 更新为具体能力类型
  - 出现在公共数据集列表中
  - 可以用于创建测评任务

#### 5.2 验证失败
- 任一环节失败的数据集：
  - `is_verified` 保持为 `false`
  - `capability_tag` 设置为相应的错误状态
  - 不出现在公共数据集列表中
  - 创建者可以根据错误信息修改后重新上传

### 6. 状态查询与轮询

#### 6.1 状态查询接口
前端可以通过 `GET /api/datasets/{id}/capability_status/` 查询数据集状态：
```json
{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "dataset_id": 1,
    "capability_tag": "processing",
    "capability_dimension": "other",
    "is_processing": true,
    "is_verified": false,
    "has_file": true
  }
}
```

#### 6.2 前端轮询机制
- 上传完成后，前端开始轮询状态接口
- 根据不同状态显示相应的UI提示
- 处理完成后停止轮询

## CSV特有的处理逻辑

### 1. 编码检测顺序
系统按以下优先级尝试编码：
1. UTF-8（推荐）
2. GBK（中文Windows常用）
3. GB2312（简体中文）
4. Latin-1（兜底）

### 2. 字段映射策略
- **输入字段**：`input` > `question` > `prompt` > `text` > 第一个非空字段
- **答案字段**：`answer` > `label` > `target` > `correct_answer`
- **参考答案字段**：`reference` > `answer` > `target` > `correct_answer`

### 3. 数据转换过程
- 读取CSV前5行数据（不包括表头）
- 将每行数据转换为JSON对象
- 根据测评类型映射字段
- 验证字段完整性和有效性

## 状态字段说明

### is_verified（验证状态）
- `false`：数据集未通过测评类型和能力分析测试
- `true`：数据集已通过测评类型和能力分析测试

### capability_tag（能力分析状态）
- `processing`：正在分析能力维度
- `no_file`：文件缺失，无法进行能力分析
- `no_samples`：无有效样本，无法进行能力分析
- `analysis_failed`：分析失败，请检查数据集格式或稍后重试
- `language`：自然语言理解能力
- `reasoning`：数学推理能力
- `coding`：代码能力
- `other`：默认状态，无法分类的数据集

## 验证规则

### 主观测评 (subjective)
- 必需列：`input`, `reference`
- 列值要求：非空字符串
- 验证内容：每行数据必须包含这两列的非空值

### 客观测评 (objective)
- 必需列：`input`, `answer`
- `input` 要求：包含至少两个选项（如 A. B. C.）
- `answer` 要求：单个选项字母（如 A/B/C）
- 验证内容：答案必须在题目选项中

### 对抗测评 (adversarial)
- 必需列：`input`
- 列值要求：非空字符串
- 验证内容：每行数据必须包含input列的非空值

## 前端集成要点

2. **状态UI展示**：根据不同状态显示相应提示
3. **错误处理**：提供清晰的错误信息和处理建议
4. **轮询限制**：最多轮询30次（约1分钟）
5. **编码提示**：建议用户使用UTF-8编码保存CSV文件

## 常见问题与解决方案

### Q1: CSV上传后提示编码错误
**原因**：系统无法使用任何支持的编码解析文件
**解决**：使用UTF-8编码重新保存CSV文件

### Q2: 上传后提示字段缺失
**原因**：CSV文件不包含对应测评类型的必需列
**解决**：检查CSV表头，确保包含必需的列名

### Q3: 客观测评提示答案格式错误
**原因**：answer列值不是单个选项字母或不在题目选项中
**解决**：确保answer列只包含A、B、C、D等单个字母

### Q4: 上传后一直显示"处理中"
**原因**：能力分析任务可能因网络问题或API调用失败而延迟
**解决**：系统有自动重试机制，最多重试3次；如持续失败，请联系管理员

### Q5: CSV文件包含特殊字符导致解析失败
**原因**：CSV中包含未正确转义的逗号、引号等特殊字符
**解决**：使用标准CSV工具导出文件，确保特殊字符正确转义

## 性能考虑

1. **文件大小限制**：100MB
2. **抽样数量**：能力分析只取前5行数据，提高处理速度
3. **编码检测**：按优先级尝试编码，避免无效尝试
4. **流式处理**：大文件按流式读取，避免内存溢出
5. **异步处理**：能力分析使用异步任务，不阻塞用户操作

## 安全机制

1. **权限控制**：只有创建者和管理员可以查看未验证的数据集
2. **隐私保护**：未验证通过的数据集只有创建者可见
3. **错误隔离**：详细的错误信息只记录在日志中，用户看到简化的提示
4. **字段验证**：严格验证CSV字段，防止注入攻击
