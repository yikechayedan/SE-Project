# PolyMetric 当前图片数据集格式支持说明

## 概述

PolyMetric平台当前采用简单高效的方式支持图片数据集，专注于测评任务的核心需求，而非支持所有可能的格式。这种设计理念确保了系统的稳定性和易用性。

## 当前支持的格式

### PolyMetric原生格式（推荐）

PolyMetric原生格式是最适合测评任务的格式，简单直观且功能完整。

#### 文件结构
```
dataset.zip
├── data.json
├── image1.jpg
├── image2.png
└── ...
```

#### JSON数据结构

**主观测评格式**：
```json
[
  {
    "id": 1,
    "input": "请描述这张图片的内容",
    "image": "image1.jpg",
    "reference": "这是一张示例图片，显示了美丽的风景"
  }
]
```

**客观测评格式**：
```json
[
  {
    "id": 1,
    "input": "图片分类",
    "image": "image1.jpg",
    "answer": "猫"
  }
]
```

**对抗测评格式**：
```json
[
  {
    "id": 1,
    "input": "这张图片有什么异常？",
    "image": "adversarial1.png"
  }
]
```

#### 支持的图片格式
- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)
- BMP (.bmp)
- WebP (.webp)
- SVG (.svg)

## 设计理念

### 1. 简单性
- 单一ZIP文件包含所有内容

- 便于传输和管理

### 3. 灵活性
- 支持三种测评类型
- 可扩展的数据结构

### 4. 兼容性
- 标准的ZIP和JSON格式
- 广泛支持的图片格式
- 跨平台兼容

## 使用方法

### 1. 准备数据集
1. 创建JSON数据文件，根据测评类型选择相应格式
2. 准备图片文件，确保JSON中的image字段与实际文件名匹配
3. 将所有文件打包成ZIP文件

### 2. 上传数据集
1. 登录PolyMetric平台
2. 导航到"数据集"页面
3. 点击"上传数据集"按钮
4. 填写数据集信息：
   - 名称：为数据集起一个描述性的名称
   - 描述：详细描述数据集内容和用途
   - 类别：选择"图像"
   - 测评类型：选择主观测评、客观测评或对抗测评
   - 文件格式：选择"ZIP"
5. 选择准备好的ZIP文件
6. 点击"上传"按钮

### 3. 系统处理
上传完成后，系统会自动：
1. 解析ZIP文件
2. 统计JSON数据中的样本数量
3. 识别并统计图片数量
4. 设置`has_images`标志为`true`
5. 保存所有相关信息到数据库

## API接口

### 上传数据集
```http
POST /api/datasets/
Content-Type: multipart/form-data

{
  "name": "示例图片数据集",
  "description": "这是一个示例图片数据集",
  "category": "image",
  "evaluation_type": "subjective",
  "file_format": "zip",
  "file_path": <ZIP文件>
}
```

### 获取图片
```http
GET /api/datasets/{dataset_id}/image/?filename=image1.jpg
```

### 获取图片列表
```http
GET /api/datasets/{dataset_id}/images/
```

### 预览数据集
```http
GET /api/datasets/{dataset_id}/preview/?limit=20
```

## 常见问题

### Q: 为什么不支持ImageNet/COCO等格式？
A: PolyMetric专注于测评任务，原生格式更适合这类需求。复杂格式会增加系统复杂度而不会带来显著优势。

### Q: 如何转换其他格式到PolyMetric格式？
A: 可以编写简单的转换脚本，将其他格式的数据转换为PolyMetric的JSON结构。

### Q: 支持哪些图片格式？
A: 支持常见的图片格式：JPEG、PNG、GIF、BMP、WebP、SVG。

### Q: 文件大小限制是多少？
A: 单个ZIP文件限制为100MB，以确保良好的上传和处理性能。

### Q: 可以在JSON中添加自定义字段吗？
A: 可以，JSON结构是灵活的，可以添加自定义字段以满足特定需求。

## 最佳实践

1. **文件命名**：使用有意义的文件名，避免特殊字符
2. **图片质量**：使用适当的分辨率，避免文件过大
3. **数据一致性**：确保JSON中的图片路径与实际文件名匹配
4. **压缩优化**：使用适当的压缩比例，平衡质量和大小
5. **测试验证**：上传前验证数据格式和内容

## 总结

PolyMetric采用简洁高效的方式支持图片数据集，专注于测评任务的核心需求。虽然不直接支持所有可能的格式，但当前方案在易用性、可靠性和性能方面都有优势，能够满足大多数测评场景的需求。

如果需要使用其他格式的数据集，可以通过简单的转换脚本将其转换为PolyMetric原生格式，这样既能利用现有数据，又能享受平台的高效处理能力。
