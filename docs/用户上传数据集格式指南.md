# 用户上传数据集格式指南

## 概述

本指南详细说明如何上传数据集到 PolyMetric 平台，包括支持的文件格式、数据结构要求和上传步骤。

## 重要说明

**测评任务与数据集格式的匹配性**：

如果测评任务选择的测评类型（主观/客观/对抗）与上传的数据集格式不匹配，系统行为如下：

1. **数据集上传阶段**：系统会根据选择的测评类型验证数据集格式。如果格式不匹配，数据集上传**会被拒绝**，并返回详细的错误信息。

2. **任务创建阶段**：即使数据集上传成功，如果在创建测评任务时选择了与数据集格式不匹配的测评类型，任务仍然可以创建成功，但在执行评测时可能会出现问题：
   - 客观测评任务使用主观格式数据集：系统会尝试从数据中提取 `answer` 字段，如果不存在，会导致评测失败
   - 主观测评任务使用客观格式数据集：系统会尝试从数据中提取 `reference` 字段，如果不存在，会导致评测失败
   - 对抗测评任务使用其他格式数据集：系统只使用 `input` 字段，通常不会失败

**建议**：确保测评任务的类型与数据集格式匹配，以避免评测过程中的错误。

## 支持的文件格式

PolyMetric 平台支持以下三种文件格式：

1. **CSV** - 适用于表格数据
2. **JSON** - 适用于结构化数据，支持三种测评类型
3. **ZIP** - 适用于包含图片的复杂数据集

所有文件格式的大小限制均为 **100MB**。

## 测评类型

数据集支持三种测评类型，不同类型有不同的字段要求：

### 1. 主观测评 (subjective)

适用于需要人工评估的场景，如文本生成、描述性任务等。

**必需字段**：
- `input` - 输入内容或问题
- `reference` - 参考答案

**示例格式**：
```json
[
  {
    "input": "请简要解释什么是操作系统。",
    "reference": "操作系统是管理计算机硬件与软件资源的系统软件。"
  },
  {
    "input": "什么是机器学习？",
    "reference": "机器学习是让计算机从数据中自动学习规律的方法。"
  }
]
```

### 2. 客观测评 (objective)

适用于有明确正确答案的场景，如选择题、分类任务等。

**必需字段**：
- `input` - 输入内容或问题
- `answer` - 正确答案

**示例格式**：
```json
[
  {
    "input": "Lichens are symbiotic organisms made of green algae and fungi. What do the green algae supply to the fungi in this symbiotic relationship?\nA. carbon dioxide\nB. food\nC. protection\nD. water",
    "answer": "B"
  },
  {
    "input": "When a switch is used in an electrical circuit, the switch can\nA. cause the charge to build.\nB. increase and decrease the voltage.\nC. cause the current to change direction.\nD. stop and start the flow of current.",
    "answer": "D"
  }
]
```

### 3. 对抗测评 (adversarial)

适用于测试模型鲁棒性的场景，通常没有标准答案。

**必需字段**：
- `input` - 输入内容或问题

**示例格式**：
```json
[
  {
    "input": "请简要解释什么是 Transformer 模型。"
  },
  {
    "input": "如果你是产品经理，如何评价一个大模型的好坏？"
  }
]
```

## 详细格式要求

### CSV 格式

1. **文件要求**：
   - 标准逗号分隔值文件
   - 支持多种编码：UTF-8、GBK、GB2312、Latin-1
   - 第一行应为表头
   - 文件大小限制为100MB

2. **系统处理**：
   - 自动统计行数（减去表头）作为样本数量
   - **会进行格式验证**，确保符合所选测评类型的字段要求
   - 支持预览功能，可以查看前N条数据

3. **测评类型要求**：

#### 主观测评CSV格式
必需字段：
- `input` - 输入内容或问题
- `reference` - 参考答案

```csv
input,reference
"请解释什么是机器学习","机器学习是让计算机从数据中自动学习规律的方法"
"什么是深度学习","深度学习是机器学习的一个子领域"
"请解释自然语言处理的基本概念","自然语言处理是人工智能的一个领域，专注于使计算机能够理解、解释和生成人类语言的技术。"
```

#### 客观测评CSV格式
必需字段：
- `input` - 输入内容或问题（可包含选项）
- `answer` - 正确答案

```csv
input,answer
"机器学习是人工智能的一个分支，它使计算机系统能够从数据中学习和改进。机器学习主要包括哪些类型？\nA. 监督学习、无监督学习、强化学习\nB. 分类学习、回归学习、聚类学习\nC. 深度学习、浅层学习、迁移学习\nD. 有标签学习、无标签学习、半标签学习","A"
"以下哪个不是深度学习框架？\nA. TensorFlow\nB. PyTorch\nC. Scikit-learn\nD. Keras","C"
```

#### 对抗测评CSV格式
必需字段：
- `input` - 输入内容或问题

```csv
input
"请解释量子计算的基本原理，以及它与传统计算的主要区别。"
"如果你是一名AI伦理专家，如何评估自动驾驶汽车在紧急情况下做出道德决策的标准？"
"请分析人工智能在医疗诊断中的应用潜力，以及可能面临的技术和伦理挑战。"
```

4. **注意事项**：
   - CSV文件**会根据选择的测评类型进行字段验证**
   - 如果字段不符合测评类型要求，上传会被拒绝
   - 建议使用UTF-8编码以确保最佳兼容性
   - 包含逗号、引号等特殊字符的字段应该用双引号包围

### JSON 格式

1. **文件要求**：
   - 必须是有效的 JSON 文件
   - 根元素必须是数组
   - 数组不能为空
   - 每个元素必须是对象（字典）

2. **系统处理**：
   - 自动验证格式是否符合所选测评类型
   - 只检查前5个数据项，提高性能
   - 自动统计数组长度作为样本数量

3. **通用结构**：
```json
[
  {
    "id": 1,  // 可选，建议添加
    "input": "问题或输入内容",
    // 根据测评类型添加其他必需字段
    "reference": "参考答案",  // 主观测评必需
    "answer": "正确答案"      // 客观测评必需
  }
]
```

### ZIP 格式（图片数据集）

1. **文件要求**：
   - 必须包含 JSON 数据文件
   - 可包含图片文件
   - 支持子目录结构
   - **重要**：图像数据集也必须遵循测评类型的字段要求

2. **推荐文件结构**：
```
dataset.zip
├── data.json        // 数据文件
├── image1.jpg        // 图片文件
├── image2.png
└── images/           // 可选子目录
    ├── image3.jpg
    └── subdir/
        └── image4.png
```

3. **图像数据集的测评类型要求**：

#### 主观测评图像数据集
每个数据项必须包含：
- `input` - 输入内容或问题
- `reference` - 参考答案
- `image` - 图片文件路径

```json
[
  {
    "id": 1,
    "input": "请描述这张图片",
    "image": "sample1.jpg",
    "reference": "这是一张风景照片，显示了山脉和湖泊"
  },
  {
    "id": 2,
    "input": "这张图片中的主要对象是什么？",
    "image": "sample2.png",
    "reference": "图片中主要是一只狗"
  }
]
```

#### 客观测评图像数据集
每个数据项必须包含：
- `input` - 输入内容或问题
- `answer` - 正确答案
- `image` - 图片文件路径

```json
[
  {
    "id": 1,
    "input": "图片分类",
    "image": "cat1.jpg",
    "answer": "猫"
  },
  {
    "id": 2,
    "input": "图片分类",
    "image": "dog1.jpg",
    "answer": "狗"
  }
]
```

#### 对抗测评图像数据集
每个数据项必须包含：
- `input` - 输入内容或问题
- `image` - 图片文件路径

```json
[
  {
    "id": 1,
    "input": "这张图片有什么异常？",
    "image": "adversarial1.png"
  },
  {
    "id": 2,
    "input": "识别这张图片",
    "image": "adversarial2.jpg"
  }
]
```

4. **支持的图片格式**：
   - JPEG (.jpg, .jpeg)
   - PNG (.png)
   - GIF (.gif)
   - BMP (.bmp)
   - WebP (.webp)
   - SVG (.svg)

## 上传步骤

### 1. 准备数据集

根据你的需求选择合适的格式：

- **文本数据**：使用 JSON 格式，选择合适的测评类型
- **表格数据**：使用 CSV 格式
- **图片数据**：使用 ZIP 格式，包含 JSON 和图片文件

### 2. 通过 API 上传

```http
POST /api/datasets/
Content-Type: multipart/form-data

name: 数据集名称
description: 数据集描述
category: 数据集类别 (text/image/multimodal)
evaluation_type: 测评类型 (subjective/objective/adversarial)
file_format: 文件格式 (csv/json/zip)
file_path: [上传的文件]
is_public: true/false
```

### 3. 系统验证

上传后，系统会自动：
1. 验证文件格式
2. 检查数据结构是否符合测评类型要求
3. 统计样本数量
4. 保存文件路径到数据库

## 验证规则

### CSV 格式验证

1. **基础验证**：
   - 文件必须是有效的 CSV 格式
   - 第一行必须包含表头
   - 文件不能为空（至少包含表头和一行数据）

2. **字段验证**：
   - 主观测评：必须包含 `input` 和 `reference` 字段
   - 客观测评：必须包含 `input` 和 `answer` 字段
   - 对抗测评：必须包含 `input` 字段
   - 系统会验证每行数据是否包含对应测评类型的必需字段

3. **编码验证**：
   - 系统会尝试使用多种编码解析文件（UTF-8、GBK、GB2312、Latin-1）
   - 如果所有编码都失败，会返回编码错误

4. **错误处理**：
   - 如果格式不符合要求，系统会返回详细错误信息
   - 错误信息会指出缺少的字段或格式问题

### JSON 格式验证

1. **基础验证**：
   - 文件必须是有效的 JSON
   - 根元素必须是数组
   - 数组不能为空

2. **字段验证**：
   - 主观测评：每个项目必须包含 `input` 和 `reference` 字段
   - 客观测评：每个项目必须包含 `input` 和 `answer` 字段
   - 对抗测评：每个项目必须包含 `input` 字段

3. **错误处理**：
   - 如果格式不符合要求，系统会返回详细错误信息
   - 错误信息会指出哪个数据项缺少哪个必需字段

### ZIP 格式验证

1. **文件检查**：
   - 必须包含至少一个 JSON 文件
   - 优先使用 `data.json` 作为数据文件
   - 统计 ZIP 中的文件数量

2. **图片处理**：
   - 自动识别图片文件
   - 统计图片数量
   - 验证 JSON 中的图片路径是否存在

3. **测评类型验证**：
   - **重要**：图像数据集现在也必须遵循测评类型的字段要求
   - 主观测评：每个项目必须包含 `input`、`reference` 和 `image` 字段
   - 客观测评：每个项目必须包含 `input`、`answer` 和 `image` 字段
   - 对抗测评：每个项目必须包含 `input` 和 `image` 字段
   - 如果格式不符合要求，系统会返回详细错误信息指出缺少的字段

## 常见问题

### Q: 上传失败怎么办？
A: 检查以下几点：
- 文件大小是否超过 100MB
- JSON 格式是否有效
- 数据结构是否符合测评类型要求
- ZIP 文件中的图片路径是否与 JSON 中的路径匹配

### Q: 可以在 JSON 中添加自定义字段吗？
A: 可以，JSON 结构是灵活的，可以添加自定义字段以满足特定需求。

### Q: 如何处理大文件？
A: 当前单个文件限制为 100MB，如需上传更大文件，请考虑分割数据集。

### Q: CSV 格式支持哪些测评类型？
A: CSV 格式支持所有三种测评类型（主观、客观、对抗），但必须包含对应测评类型的必需字段：
- 主观测评：需要 `input` 和 `reference` 字段
- 客观测评：需要 `input` 和 `answer` 字段
- 对抗测评：只需要 `input` 字段

### Q: CSV 文件上传失败怎么办？
A: 检查以下几点：
- 确保文件是有效的CSV格式，第一行为表头
- 检查是否包含了对应测评类型的所有必需字段
- 确认文件编码（推荐使用UTF-8）
- 验证文件大小不超过100MB
- 检查数据行是否包含特殊字符，必要时用双引号包围

### Q: CSV 文件中可以使用特殊字符吗？
A: 可以，但需要注意：
- 包含逗号的字段应该用双引号包围
- 包含双引号的字段应该用两个双引号表示
- 推荐使用UTF-8编码以避免字符编码问题

### Q: 图片路径可以使用绝对路径吗？
A: 不可以，图片路径必须使用相对于 ZIP 根目录的相对路径。

## 最佳实践

1. **文件命名**：
   - 使用有意义的文件名
   - 避免使用特殊字符
   - 图片文件名应与 JSON 中的路径一致

2. **数据准备**：
   - 上传前验证数据格式
   - 确保必需字段完整
   - 添加 ID 字段便于追踪

3. **图片优化**：
   - 使用适当的图片分辨率
   - 选择合适的图片格式
   - 控制单个图片文件大小

4. **测试验证**：
   - 先用小数据集测试
   - 检查上传后的预览结果
   - 验证数据解析是否正确
