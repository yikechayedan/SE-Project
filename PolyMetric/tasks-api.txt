二、完整 API 说明（对齐用户接口格式）
1. 新建评测任务
接口：POST /api/tasks/evaluation-tasks/
权限：登录用户
请求示例：
json
{
  "name": "GPT-4V 图像分类评测",
  "description": "使用 COCO 数据集测试 GPT-4V 的图像分类能力",
  "dataset": 1  // 关联数据集的 ID（必填）
}
成功返回（201 Created）：
json
{
  "id": 1,
  "name": "GPT-4V 图像分类评测",
  "description": "使用 COCO 数据集测试 GPT-4V 的图像分类能力",
  "creator": 1,
  "creator_username": "testuser",
  "dataset": 1,
  "dataset_name": "COCO 2017",
  "status": "pending",
  "accuracy": null,
  "precision": null,
  "recall": null,
  "f1_score": null,
  "created_at": "2025-11-30T10:00:00Z",
  "updated_at": "2025-11-30T10:00:00Z"
}
失败返回（400 Bad Request）：
json
{
  "error": "{'name': ['该字段为必填项'], 'dataset': ['该字段为必填项']}"
}

3. 查看单个评测任务详情
接口：GET /api/tasks/evaluation-tasks/{id}/（替换 {id} 为任务 ID）
权限：任务创建者或管理员
成功返回（200 OK）：
json
{
  "id": 1,
  "name": "GPT-4V 图像分类评测",
  "description": "使用 COCO 数据集测试 GPT-4V 的图像分类能力",
  "creator": 1,
  "creator_username": "testuser",
  "dataset": 1,
  "dataset_name": "COCO 2017",
  "status": "pending",
  "accuracy": null,
  "precision": null,
  "recall": null,
  "f1_score": null,
  "created_at": "2025-11-30T10:00:00Z",
  "updated_at": "2025-11-30T10:00:00Z"
}
权限不足返回（403 Forbidden）：
json
{
  "error": "仅任务创建者或管理员可操作此评测任务"
}
4. 编辑评测任务（全量更新）
接口：PUT /api/tasks/evaluation-tasks/{id}/
权限：任务创建者或管理员
请求示例：
json
{
  "name": "GPT-4V 图像分类评测（V2）",
  "description": "使用 COCO 2017 数据集测试 GPT-4V 的图像分类能力（优化版）",
  "dataset": 1  // 可保持原数据集，也可修改为其他数据集ID
}
成功返回（200 OK）：
json
{
  "id": 1,
  "name": "GPT-4V 图像分类评测（V2）",
  "description": "使用 COCO 2017 数据集测试 GPT-4V 的图像分类能力（优化版）",
  "creator": 1,
  "creator_username": "testuser",
  "dataset": 1,
  "dataset_name": "COCO 2017",
  "status": "pending",
  "accuracy": null,
  "precision": null,
  "recall": null,
  "f1_score": null,
  "created_at": "2025-11-30T10:00:00Z",
  "updated_at": "2025-11-30T11:20:00Z"
}
5. 部分更新评测任务
接口：PATCH /api/tasks/evaluation-tasks/{id}/
权限：任务创建者或管理员
请求示例（仅修改名称）：
json
{
  "name": "GPT-4V 图像分类评测（最终版）"
}
成功返回（200 OK）：
json
{
  "id": 1,
  "name": "GPT-4V 图像分类评测（最终版）",
  "description": "使用 COCO 2017 数据集测试 GPT-4V 的图像分类能力（优化版）",
  "creator": 1,
  "creator_username": "testuser",
  "dataset": 1,
  "dataset_name": "COCO 2017",
  "status": "pending",
  "accuracy": null,
  "precision": null,
  "recall": null,
  "f1_score": null,
  "created_at": "2025-11-30T10:00:00Z",
  "updated_at": "2025-11-30T11:30:00Z"
}
6. 删除评测任务
接口：DELETE /api/tasks/evaluation-tasks/{id}/
权限：任务创建者或管理员
成功返回：204 No Content（无响应体）
失败返回（403 Forbidden）：
json
{
  "error": "仅任务创建者或管理员可操作此评测任务"
}
